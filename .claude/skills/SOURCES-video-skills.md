# Video skills (third-party, copied unchanged)

Added 2026-11-03 at the owner's request, for making reels.

- `remotion-*`: from https://github.com/remotion-dev/skills (commit c7cb2fdc, 2026-11-02), Remotion's
  own agent skills, published for installing into agents (`npx skills add remotion-dev/skills`).
  Left out: remotion-maps, remotion-saas. Remotion itself has its own license: free for
  individuals and companies of up to 3 people (see the remotion-license skill).
- `hyperframes`, `hyperframes-cli`, `hyperframes-registry`, `media-use`, `remotion-to-hyperframes`,
  `reverse-any-video`, `style-sampling`: from https://github.com/heygen-com/hyperframes (commit
  a5a61213, 2026-11-03), Apache License 2.0, see LICENSE-hyperframes. Left out: figma, slideshow.

To update, copy the same folders again from the repos' latest versions.
